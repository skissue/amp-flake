#+title: Amp Desktop for NixOS
#+author: Ad <me@skissue.xyz>

An unofficial flake providing a NixOS repackage of the [[https://ampcode.com/docs/apps/linux][Amp for Linux desktop app]].

* Usage
The flake provides package outputs for both x86-64 and arm64, as well as a nixpkgs overlay.

The default =amp-desktop= package bundles =amp-cli= (from nixpkgs) for the desktop app's embedded runner. Use =amp-desktop-no-runner= to omit the bundled CLI (the app will use its normal CLI discovery).

Example usage:
#+begin_src nix
  {
    description = "My NixOS configuration";

    inputs = {
      nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
      amp-desktop = {
        url = "github:skissue/amp-flake";
        inputs.nixpkgs.follows = "nixpkgs";
      };
    };

    outputs = {
      nixpkgs,
      amp-desktop,
      ...
    }: {
      nixosConfigurations.hostname = nixpkgs.lib.nixosSystem {
        modules = [
          ./configuration.nix
          (
            {
              lib,
              pkgs,
              ...
            }: {
              nixpkgs.overlays = [amp-desktop.overlays.default];
              nixpkgs.config.allowUnfreePredicate = p: builtins.elem (lib.getName p) ["amp-desktop" "amp-cli"];
              environment.systemPackages = [
                pkgs.amp-desktop
                # If you don't want amp-cli from nixpkgs
                # pkgs.amp-desktop-no-runner
              ];
            }
          )
        ];
      };
    };
  }
#+end_src

The CLI dependency can also be customized with =pkgs.amp-desktop.override { amp-cli = pkgs.amp-cli; }=,
or disabled with =pkgs.amp-desktop.override { amp-cli = null; }= (equivalent to =amp-desktop-no-runner=).

* Known issues
+ The "Open at Login" setting is broken because of the Electron repackaging.
